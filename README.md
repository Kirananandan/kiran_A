# Kiran A — Developer Portfolio

A dark, editorial portfolio for Kiran A, built with Next.js, TypeScript and Tailwind CSS.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Static typed project content

## Local development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project routes

- `/` — portfolio homepage
- `/work/fincil` — Fincil case study
- `/work/packright` — PackRight case study
- `/work/personal-ai-agent` — Personal AI Agent case study

Set `NEXT_PUBLIC_SITE_URL` in production so the generated sitemap and robots metadata use the deployed URL.

## Validation

```bash
npm run lint
npm run build
```
